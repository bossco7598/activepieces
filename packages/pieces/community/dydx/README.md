# dYdX

dYdX is a decentralized exchange (DEX) focused on perpetual contracts and margin trading. It operates as a standalone Cosmos appchain (dYdX Chain / dYdX v4), enabling fully decentralized perpetuals trading with up to 20x leverage. DYDX is the native governance and staking token.

## Actions

- **Get Protocol TVL** — Current TVL from DeFiLlama with 1h/1d/7d changes
- **Get DYDX Token Price** — Live DYDX price, market cap, 24h volume from CoinGecko
- **Get Chain TVL Breakdown** — TVL by chain
- **Get TVL History** — Historical TVL data points
- **Get Protocol Stats** — Comprehensive protocol + token stats summary
